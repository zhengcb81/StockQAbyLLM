## 独立复验

- 日常入口为 `python -B scripts/checks.py`。它包含真实 CLI 预检、真实子进程强停及完成、异步 provider、已付结果回读和模块边界。
- 在临时归档只重跑测试时，可通过 `scripts.checks.DAILY_TEST_TARGETS` 和 `BASE_PYTEST_ARGS` 取得同一选择，pytest 指定独立 `--basetemp`。
- 冷读使用原运行留下的目录。运行 `python -B -m src.utils.quick_scan_feedback_owner --observation-dir <原收件目录> --log-dir <原日志目录> runtime-history --run-id <业务运行号> --attempt-id <原尝试号>`。人工复验只在使用合成供应商的独立工作目录执行。
